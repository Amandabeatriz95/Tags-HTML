Aprendendo sobre as tags

O que são tags?

Tags são elementos que definem a estrutura e o conteúdo de uma página web.
Elas são usadas para marcar diferentes partes do conteúdo, como títulos, parágrafos, links, imagens e muito mais. Cada tag tem uma função específica e é representada por um nome entre colchetes angulares (< >).

Os principais tipos de tags incluem:
  • Tags de cabeçalho (h1, h2, h3, etc.)
  • Tag de parágrafo (p)
  • Tag de link (a)

  • Sobre HTML - RESUMO

O HTML (HyperText Markup Language) é a linguagem de marcação padrão utilizada para estruturar páginas na web. Ele funciona como o "esqueleto" de um site, organizando o conteúdo que será exibido aos usuários. Não é uma linguagem de programação, mas sim uma ferramenta baseada em tags (etiquetas) que definem elementos visuais e textuais. Estrutura componentes fundamentais como títulos, parágrafos, imagens, links, tabelas e formulários. A estrutura básica de um documento HTML é composta pelas tags <html>, <head> (metadados) e <body> (conteúdo visível). Trabalha em conjunto com o CSS (responsável pelo estilo e design) e o JavaScript (responsável pela interatividade). Sua sintaxe utiliza tags de abertura (ex: <h1>) e de fechamento (ex: </h1>) para delimitar cada elemento. Permite a criação de hipertextos, conectando diferentes páginas, documentos e recursos pela internet. É interpretado diretamente pelos navegadores web (como Chrome, Firefox e Safari) para renderizar a página final. A versão atual, o HTML5, traz recursos modernos como tags semânticas e suporte nativo a áudio e vídeo.

Para te ajudar a complementar e estender o seu material sobre HTML mantendo o mesmo padrão de qualidade e o formato em tópicos, aqui estão mais alguns pontos importantes que você pode adicionar: Os navegadores possuem um mecanismo chamado DOM (Document Object Model), que transforma o HTML em uma árvore de elementos interativa para manipulação. O uso de comentários em HTML (<!-- texto -->) permite deixar recados no código que não aparecem para o usuário final. Permite a inserção de imagens de forma isolada usando a tag <img>, que é uma tag vazia e não exige fechamento. Organiza dados tabulares complexos utilizando a combinação das tags <table>, <tr>, <th> e <td>. Cria campos de entrada de dados interativos com a tag <input> dentro de formulários <form>. O HTML5 introduziu tags semânticas poderosas (como <header>, <nav>, <section> e <footer>) que dão significado real à estrutura da página. É fundamental para a acessibilidade web, permitindo o uso de atributos como o alt em imagens para leitores de tela. Garante a responsividade básica e a adaptação para dispositivos móveis quando combinado com as meta tags corretas de viewport. Pode carregar arquivos externos de estilo e scripts através de tags específicas como <link> e <script>. É a base obrigatória para qualquer desenvolvedor Fullstack, sendo o ponto de partida de toda a interface web.

  • Tags de cabeçalho

(Voltar)

As tags de cabeçalho vão de <h1> até <h6> e servem para definir títulos e subtítulos no HTML. Organizam o conteúdo em ordem de importância, criando uma hierarquia clara na página. O <h1> é o título principal e mais importante, devendo aparecer apenas uma vez por página. As tags <h2> até <h6> são usadas para criar seções e subseções secundárias. Melhoram drasticamente a legibilidade para os usuários que leem o texto rapidamente. São fundamentais para o SEO, ajudando os buscadores como o Google a entenderem o tema do site. Auxiliam a acessibilidade, permitindo que leitores de tela naveguem facilmente pelos tópicos. Sua sintaxe utiliza elementos de abertura e fechamento, como por exemplo <h2> e </h2>.


  • Tag de parágrafo

(Voltar)

A tag de parágrafo em HTML é representada por <p> e serve para estruturar blocos de texto. É uma das tags mais fundamentais e utilizadas na criação de qualquer página web. Sua sintaxe exige uma tag de abertura (<p>) e uma tag de fechamento (</p>). Os navegadores adicionam automaticamente um espaço em branco (margem) acima e abaixo de cada parágrafo. Ajuda a organizar o conteúdo textual, separando ideias e melhorando a leitura visual. Permite inserir formatações internas, como negrito, itálico e links, sem quebrar a estrutura. Não deve ser usada para títulos ou cabeçalhos, pois possui um propósito puramente semântico de texto corrido. Garante melhor acessibilidade e legibilidade tanto para os usuários quanto para mecanismos de busca.

  • Tag de link

(Voltar)

A tag de link em HTML é representada pela letra , abreviação de anchor (âncora). É a tag responsável por criar hiperlinks, permitindo navegar entre páginas da web, sites ou documentos. Sua sintaxe básica exige o atributo href para indicar o endereço de destino (URL) do link. Exemplo prático de uso: <a href="[https://exemplo.com](https://exemplo.com)">Clique aqui</a>. Pode ser usada para abrir links na mesma aba ou em uma nova aba utilizando o atributo target="_blank". Permite também criar links internos na mesma página, utilizando IDs como âncoras (ex: <a href="#secao">). Serve para criar links de contato direto, como e-mails (mailto:) e números de telefone (tel:). O texto que fica entre a tag de abertura e de fechamento é a parte clicável que o usuário enxerga na tela. É um dos pilares fundamentais da web, transformando documentos isolados em uma rede conectada de informações. Pode envolver outros elementos HTML, como imagens ou botões, transformando-os em elementos interativos. Ajuda na experiência do usuário (UX), guiando a navegação de forma intuitiva e fluida pelo site. É essencial para o SEO, pois os buscadores usam os links para mapear e indexar diferentes páginas da internet. Exige boas práticas de acessibilidade, devendo usar textos descritivos no link em vez de termos genéricos como "clique aqui". Sua estilização visual padrão nos navegadores costuma ser um texto azul e sublinhado, mas isso pode ser alterado via CSS. É uma das tags mais versáteis e indispensáveis para qualquer desenvolvedor web Fullstack.
