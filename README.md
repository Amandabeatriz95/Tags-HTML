# 📚 Aprendendo sobre Tags HTML

Este repositório contém uma página web desenvolvida para consolidar os estudos iniciais sobre **HTML (HyperText Markup Language)**, servindo como um guia de referência rápida sobre estruturas básicas e tags essenciais da web.

## 🚀 Sobre o Projeto
O projeto foi construído puramente em HTML semântico, estruturando conceitos fundamentais que todo desenvolvedor web precisa dominar no início da jornada de transição para **Fullstack**.

## 📌 Conteúdos Abordados na Página
* **O que são tags:** Definição e função na estruturação web.
* **Resumo sobre HTML:** O papel do HTML, sua relação com CSS/JavaScript, DOM e HTML5.
* **Tags de Cabeçalho (`<h1>` a `<h6>`):** Hierarquia, SEO e organização de títulos.
* **Tag de Parágrafo (`<p>`):** Estruturação e semântica para blocos de texto.
* **Tag de Link (`<a>`):** Criação de hiperlinks, atributos importantes e navegação interna/externa.

## 🛠️ Tecnologias Utilizadas
* **HTML5** (Estruturação e marcação semântica)

## 🌐 Como Visualizar
Você pode clonar este repositório e abrir o arquivo `.html` diretamente no seu navegador de preferência (Google Chrome, Firefox, Edge, etc.) para navegar pelo conteúdo e testar os links internos.
